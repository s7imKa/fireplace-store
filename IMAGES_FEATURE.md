# Функція декількох фото для товару

## Що було додано

### 1. Підтримка масиву зображень

-   Тип `Product` тепер має поле `images: string[]` для зберігання декількох URL фотографій
-   Збережена зворотна сумісність з полем `imageUrl` для старих товарів

### 2. Адмін панель

-   Можливість завантажити **декілька фото одночасно** при додаванні/редагуванні товару
-   Попередній перегляд усіх обраних фото перед збереженням
-   Можливість видалити окремі фото з попереднього перегляду
-   Сітка для зручного перегляду всіх завантажених фотографій
-   Кнопка ✕ на кожному фото для видалення

### 3. Список товарів (головна сторінка)

-   На карточці товару відображається **перше фото** з масиву
-   Якщо масив порожній, використовується старе поле `imageUrl` (backward compatibility)

### 4. Сторінка ProductDetail

-   **Слайдер фотографій** з можливістю перегортання
-   Кнопки ‹ › для навігації між фото
-   Точки-індикатори внизу для швидкого переходу до потрібного фото
-   Активна точка показує поточне фото
-   Якщо фото лише одне - слайдер не показується, відображається просто фото

### 5. Адаптивний дизайн

-   Слайдер коректно працює на мобільних пристроях
-   Кнопки та індикатори адаптовані під різні розміри екранів

## Як використовувати

### Додавання товару з декількома фото

1. Перейдіть в адмін-панель
2. Натисніть на поле "Фото товару"
3. Оберіть **декілька файлів** одночасно (Ctrl/Cmd + клік або виділення)
4. Побачите попередній перегляд всіх обраних фото
5. Можете додати ще фото, знову натиснувши на поле вибору
6. При потребі видаліть непотрібні фото кнопкою ✕
7. Збережіть товар

### Редагування фото існуючого товару

1. Натисніть "Редагувати" на потрібному товарі
2. Побачите всі вже завантажені фото
3. Можете видалити будь-яке фото кнопкою ✕
4. Можете додати нові фото
5. Збережіть зміни

### Перегляд товару на сайті

-   На головній сторінці буде показане перше фото
-   На сторінці товару можна переглянути всі фото через слайдер:
    -   Кнопками ‹ › переключайте фото
    -   Або клікайте на точки внизу
    -   Свайп на мобільних пристроях (якщо додасте touch підтримку)

## Технічні деталі

### Структура даних в Firestore

```json
{
  "name": "Камін XYZ",
  "price": 15000,
  "images": [
    "https://i.ibb.co/xxx/image1.jpg",
    "https://i.ibb.co/yyy/image2.jpg",
    "https://i.ibb.co/zzz/image3.jpg"
  ],
  "imageUrl": "https://i.ibb.co/xxx/image1.jpg",
  ...
}
```

-   `images[]` - масив всіх фотографій
-   `imageUrl` - перше фото (для backward compatibility)

## Обмеження

-   Максимальний розмір одного файлу: 32MB (обмеження ImgBB API)
-   Підтримувані формати: JPG, PNG, WebP, GIF
-   Рекомендується не завантажувати більше 5-7 фото на товар для швидкості завантаження
